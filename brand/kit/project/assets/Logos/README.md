# Logos

The Leva mark and wordmark, outlined (no font needed). Colours are baked in: `accent` #d0106f, `ink` #000000, `bg` #f7f7f5.

- `leva-lockup.svg`: mark + wordmark on light grounds (`bg`, `surface`, `field-1`…`field-4`). The default.
- `leva-lockup-on-dark.svg`: the same on `ink` or dark photography; the ink block and the word become `bg`.
- `leva-mark.svg`: the mark alone, under 24px tall, favicons, the MCP server's avatar.
- `leva-mark-on-dark.svg`: the mark on dark grounds.
- `leva-mark-mono-ink.svg`: one-colour print only; both blocks in `ink`.
- `leva-wordmark.svg`, `leva-wordmark-on-dark.svg`: the word alone, where the mark already appears nearby.
- `leva-app-icon.svg`: the mark on `bg` with 22% padding, the source of the 192 and 512px PNG icons.

Clear space is the width of the mark's ink block on every side. Minimum size: mark 16px, lockup 20px tall. Never recolour, reorder, round or re-proportion the blocks.
